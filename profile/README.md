# ha-termoweb

Home Assistant integrations for electric heaters and thermostats sold under the TermoWeb, Tevolve and Ducaheat apps (brands include ATC, Ducasa, Soler & Palau, Ecotermi, EHC and Eco Save).

## Projects

| Repository | What it does |
|---|---|
| [ha-termoweb](https://github.com/ha-termoweb/ha-termoweb) | Home Assistant integration for TermoWeb, Tevolve and Ducaheat heaters, through the vendor cloud or a local 868 MHz radio. |
| [ha-termoweb-local](https://github.com/ha-termoweb/ha-termoweb-local) | Cloud-free control of Sun Ray RF heaters from Home Assistant, using a nanoCUL868 (CC1101) USB stick and the firmware in the repo in place of the vendor gateway. |

Both install through [HACS](https://hacs.xyz/) as custom repositories. Each repository's README covers requirements, installation and known limitations.

## Getting help

Open an issue in the repository for the integration you use. Include your Home Assistant version, the integration version and the relevant log lines, with any serial numbers, device ids or account details removed.
